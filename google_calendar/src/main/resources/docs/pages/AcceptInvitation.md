# Accept Invitation

## Overview

Accepts a meeting invitation for a specific attendee, updating their response status to "accepted" in the calendar event.

## Request Details

- **Area**: Meetings
- **Type**: CHANGE_SYSTEM
- **Retry Support**:  Yes (Idempotent operation - accepting an already accepted invitation has no adverse effect)

## Input Parameters

| Parameter Name | Type | Required | Description | Example |
|----------------|------|----------|-------------|---------|
| Event Id | Text | Yes | Unique identifier of the calendar event | "abc123def456ghi789" |
| Attendee Email | Email | Yes | Email address of the attendee accepting the invitation | "john.doe@company.com" |

### Parameter Details

**Event Id**:
- Unique identifier generated by Google Calendar
- Must be a valid, existing event ID
- Case-sensitive alphanumeric string
- Obtained from meeting invitations or other calendar operations

**Attendee Email**:
- Must be a valid email address format
- Must be an existing attendee on the event
- Case-insensitive email matching
- Must have received the original invitation

## Output Parameters

| Parameter Name | Type | Description |
|----------------|------|-------------|
| Event Details | Entity(Event Details) | Updated event information with modified attendee status |

### Event Details Entity Structure

- **Event Id**: Unique event identifier
- **Title**: Event title/summary
- **Location**: Event location
- **Date From**: Event start date and time
- **Date To**: Event end date and time
- **Details**: Event description
- **Contacts**: List of all attendee email addresses with updated status

## Validation Rules

| Validation | Error Message | Resolution |
|------------|---------------|------------|
| Event ID is required | "Event ID cannot be empty" | Provide a valid Event ID |
| Attendee Email is required | "Attendee email cannot be empty" | Provide a valid email address |
| Valid email format | "Invalid email address format" | Use proper email format (user@domain.com) |
| Event must exist | "Event not found" | Verify Event ID exists and is accessible |
| Attendee must be invited | "Attendee not found in event" | Ensure email is in the original attendee list |

## Error Handling

### Input Errors (INPUT_ERROR)
**Cause**: Invalid or missing required parameters
**Common Scenarios**:
- Empty Event ID or attendee email
- Malformed email address
- Invalid Event ID format

**Resolution**: Validate all input parameters before submission

### Logic Errors (LOGIC_ERROR)
**Cause**: Business logic validation failures
**Common Scenarios**:
- Event not found or inaccessible
- Attendee email not in event attendee list
- Event already cancelled or deleted
- Insufficient permissions to modify event

**Resolution**: Verify event exists and attendee has proper access

### System Errors (SYSTEM_ERROR)
**Cause**: Google Calendar API failures or network issues
**Common Scenarios**:
- API rate limiting
- Network connectivity problems
- Google service outages
- Authentication token expiration

**Error Message**: "Invitation acceptance failed: Unable to update event response status. Required: Valid Event ID and attendee email with pending invitation. Resolution: Verify event exists, attendee has pending invitation, and check Google Calendar API connectivity."

**Resolution**: Retry request after delay or re-authenticate if needed

### Authorization Errors
**Cause**: Insufficient permissions or expired authentication
**Common Scenarios**:
- User not authorized to modify the event
- OAuth token expired or invalid
- Calendar access permissions revoked

**Resolution**: Re-authenticate or verify calendar permissions

## Business Rules

1. **Attendee Validation**: Only existing attendees can accept invitations
2. **Status Update**: Changes attendee response status from "needsAction" or "declined" to "accepted"
3. **Notification Sending**: Google Calendar automatically notifies organizer of acceptance
4. **Idempotent Operation**: Accepting an already accepted invitation has no negative effect
5. **Permission Requirements**: User must have modify access to the event
6. **Event Status**: Can accept invitations for confirmed, tentative, or cancelled events
7. **Multiple Acceptances**: Same attendee can change response multiple times

## Limitations

1. **Single Attendee**: Accepts invitation for one attendee per request
2. **Existing Attendees Only**: Cannot accept on behalf of non-invited attendees
3. **Event Dependency**: Event must exist and be accessible
4. **Permission Dependent**: Requires appropriate calendar permissions
5. **API Rate Limits**: Subject to Google Calendar API quotas
6. **No Bulk Operations**: Cannot accept multiple invitations simultaneously

## Best Practices

### 1. **Validate Attendee Status**
Check if attendee is actually invited before attempting acceptance

### 2. **Handle Idempotency**
Design systems to handle multiple acceptance attempts gracefully

### 3. **Error Recovery**
Implement proper error handling for network failures and API issues

### 4. **User Feedback**
Provide clear feedback to users about acceptance status

### 5. **Permission Checking**
Verify user permissions before attempting to accept invitations

## Technical Implementation

### Helper Class
- **Class**: MeetingAreaImpl
- **Package**: app.kristasoft.extensions.essentials.collaboration.google_calendar.impl
- **Method**: acceptInvitation(String eventId, String emailId)
- **Service**: Google Calendar API events.patch()

### Implementation Details
1. **Retrieve Event**: Get event details using events.get()
2. **Find Attendee**: Locate attendee in event's attendee list by email
3. **Update Status**: Set attendee's responseStatus to "accepted"
4. **Patch Event**: Update event using events.patch() with modified attendee list
5. **Return Details**: Convert updated event to EventDetails entity

### API Integration
- **API Endpoint**: Google Calendar API v3 events.patch
- **Authentication**: OAuth 2.0 with calendar scope
- **Request**: PATCH /calendars/primary/events/{eventId}
- **Response**: Updated Event object with modified attendee status

## Troubleshooting

### Attendee Not Found
**Cause**: Email address not in event attendee list
**Solution**: Verify attendee was originally invited to the event

### Permission Denied
**Cause**: Insufficient permissions to modify event
**Solution**: Ensure user has appropriate calendar access rights

### Event Not Found
**Cause**: Invalid Event ID or deleted event
**Solution**: Verify Event ID is correct and event still exists

### Already Accepted
**Cause**: Invitation already accepted (not an error)
**Solution**: Operation completes successfully due to idempotent nature
