# Add Attendees

## Overview

Adds one or more attendees to an existing calendar event, sending them invitations and updating the event's attendee list.

## Request Details

- **Area**: Meetings
- **Type**: CHANGE_SYSTEM
- **Retry Support**:  No (Adding attendees multiple times could result in duplicate invitations and confusion)

## Input Parameters

| Parameter Name | Type | Required | Description | Example |
|----------------|------|----------|-------------|---------|
| Event Id | Text | Yes | Unique identifier of the calendar event | "abc123def456ghi789" |
| Attendee Email | List<Email> | Yes | List of email addresses to add as attendees | ["newuser@company.com", "external@client.com"] |

### Parameter Details

**Event Id**:
- Unique identifier generated by Google Calendar
- Must be a valid, existing event ID
- Case-sensitive alphanumeric string
- Event must be accessible and modifiable by the authenticated user

**Attendee Email**:
- List of valid email addresses to add to the event
- Each email must be in proper format (user@domain.com)
- Can include both internal and external email addresses
- Duplicate emails in the list will be handled gracefully
- Cannot add attendees who are already invited to the event

## Output Parameters

| Parameter Name | Type | Description |
|----------------|------|-------------|
| Event Details | Entity(Event Details) | Updated event information with new attendees included |

### Event Details Entity Structure

- **Event Id**: Unique event identifier
- **Title**: Event title/summary
- **Location**: Event location
- **Date From**: Event start date and time
- **Date To**: Event end date and time
- **Details**: Event description
- **Contacts**: Complete list of attendee email addresses including newly added ones

## Validation Rules

| Validation | Error Message | Resolution |
|------------|---------------|------------|
| Event ID is required | "Event ID cannot be empty" | Provide a valid Event ID |
| Attendee Email list is required | "At least one attendee email is required" | Provide one or more email addresses |
| Valid email format | "Invalid email address format" | Use proper email format for all addresses |
| Event must exist | "Event not found" | Verify Event ID exists and is accessible |
| Event must be modifiable | "Insufficient permissions to modify event" | Ensure user has edit access to the event |
| Attendee limit validation | "Maximum attendee limit exceeded" | Keep total attendees under Google Calendar limits |

## Error Handling

### Input Errors (INPUT_ERROR)
**Cause**: Invalid or missing required parameters
**Common Scenarios**:
- Empty Event ID or attendee email list
- Malformed email addresses in the list
- Invalid Event ID format

**Resolution**: Validate all input parameters before submission

### Logic Errors (LOGIC_ERROR)
**Cause**: Business logic validation failures
**Common Scenarios**:
- Event not found or inaccessible
- User lacks permission to modify the event
- Event is cancelled or deleted
- Attempting to add attendees who are already invited
- Exceeding maximum attendee limits

**Resolution**: Verify event exists, user has permissions, and attendees are not duplicates

### System Errors (SYSTEM_ERROR)
**Cause**: Google Calendar API failures or network issues
**Common Scenarios**:
- API rate limiting
- Network connectivity problems
- Google service outages
- Authentication token expiration

**Error Message**: "Attendee addition failed: Unable to add new attendees to calendar event. Required: Valid Event ID and attendee email addresses. Resolution: Verify event exists, attendee emails are valid, and check Google Calendar API connectivity."

**Resolution**: Retry request after delay or re-authenticate if needed

### Authorization Errors
**Cause**: Insufficient permissions or expired authentication
**Common Scenarios**:
- User not authorized to modify the event
- OAuth token expired or invalid
- Calendar access permissions revoked

**Resolution**: Re-authenticate or verify calendar permissions

## Business Rules

1. **Event Modification Rights**: User must have edit permissions for the event
2. **Attendee Limits**: Total attendees cannot exceed Google Calendar limits (typically 100)
3. **Duplicate Prevention**: System prevents adding attendees who are already invited
4. **Invitation Sending**: New attendees automatically receive calendar invitations
5. **Organizer Permissions**: Only organizers and users with edit access can add attendees
6. **Event Status**: Can add attendees to confirmed, tentative, or even cancelled events
7. **External Attendees**: External email addresses are supported and will receive invitations

## Limitations

1. **No Bulk Event Operations**: Can only add attendees to one event per request
2. **Permission Dependent**: Requires edit access to the target event
3. **No Attendee Role Assignment**: Cannot specify attendee roles (required, optional, etc.)
4. **Limited Validation**: Cannot validate if email addresses are active before adding
5. **API Rate Limits**: Subject to Google Calendar API quotas
6. **No Undo Operation**: No direct way to undo attendee additions (must use Remove Attendee)

## Best Practices

### 1. **Validate Email Addresses**
Verify email format and avoid adding invalid addresses

### 2. **Check Existing Attendees**
Review current attendee list to prevent duplicate additions

### 3. **Batch Operations**
Add multiple attendees in a single request when possible

### 4. **Permission Verification**
Ensure user has appropriate permissions before attempting to add attendees

### 5. **Error Handling**
Implement robust error handling for various failure scenarios

### 6. **User Notification**
Inform users about successful attendee additions and any failures

## Technical Implementation

### Helper Class
- **Class**: MeetingAreaImpl
- **Package**: app.kristasoft.extensions.essentials.collaboration.google_calendar.impl
- **Method**: addAttendees(String eventId, List<String> attendees)
- **Service**: Google Calendar API events.patch()

### Implementation Details
1. **Retrieve Event**: Get current event details using events.get()
2. **Create Attendee Objects**: Convert email list to EventAttendee objects
3. **Merge Attendee Lists**: Add new attendees to existing attendee list
4. **Update Event**: Patch event with updated attendee list
5. **Return Details**: Convert updated event to EventDetails entity

### Attendee Processing
The system uses `getEventAttendees()` helper method to:
- Convert email strings to EventAttendee objects
- Set default response status to "needsAction"
- Handle email validation and formatting

### API Integration
- **API Endpoint**: Google Calendar API v3 events.patch
- **Authentication**: OAuth 2.0 with calendar scope
- **Request**: PATCH /calendars/primary/events/{eventId}
- **Response**: Updated Event object with expanded attendee list

## Troubleshooting

### Event Not Found
**Cause**: Invalid Event ID or deleted event
**Solution**: Verify Event ID is correct and event still exists

### Permission Denied
**Cause**: Insufficient permissions to modify event
**Solution**: Ensure user has edit access to the event

### Duplicate Attendees
**Cause**: Attempting to add already invited attendees
**Solution**: Check current attendee list before adding new ones

### Invalid Email Addresses
**Cause**: Malformed email addresses in the input list
**Solution**: Validate email format before submission

### Attendee Limit Exceeded
**Cause**: Total attendees would exceed Google Calendar limits
**Solution**: Remove some existing attendees or split into multiple events
