# Cancel Event

## Overview

Cancels an existing calendar event, removing it from all attendees' calendars and sending cancellation notifications.

## Request Details

- **Area**: Meetings
- **Type**: CHANGE_SYSTEM
- **Retry Support**:  Yes (Idempotent operation - cancelling an already cancelled event has no adverse effect)

## Input Parameters

| Parameter Name | Type | Required | Description | Example |
|----------------|------|----------|-------------|---------|
| Event Id | Text | Yes | Unique identifier of the calendar event to cancel | "abc123def456ghi789" |

### Parameter Details

**Event Id**:
- Unique identifier generated by Google Calendar
- Must be a valid, existing event ID
- Case-sensitive alphanumeric string
- Event must be accessible and modifiable by the authenticated user

## Output Parameters

| Parameter Name | Type | Description |
|----------------|------|-------------|
| Event Details | Entity(Event Details) | Details of the cancelled event (as it existed before cancellation) |

### Event Details Entity Structure

- **Event Id**: Unique event identifier
- **Title**: Event title/summary
- **Location**: Event location
- **Date From**: Event start date and time
- **Date To**: Event end date and time
- **Details**: Event description
- **Contacts**: List of attendee email addresses who were invited

## Validation Rules

| Validation | Error Message | Resolution |
|------------|---------------|------------|
| Event ID is required | "Event ID cannot be empty" | Provide a valid Event ID |
| Event must exist | "Event not found" | Verify Event ID exists and is accessible |
| Event must be modifiable | "Insufficient permissions to cancel event" | Ensure user has delete/modify access to the event |
| User must be organizer | "Only organizer can cancel event" | Verify user is the event organizer or has admin rights |

## Error Handling

### Input Errors (INPUT_ERROR)
**Cause**: Invalid or missing Event ID parameter
**Common Scenarios**:
- Empty or null Event ID
- Malformed Event ID string
- Event ID with invalid characters

**Resolution**: Provide a valid Event ID obtained from other calendar operations

### Logic Errors (LOGIC_ERROR)
**Cause**: Business logic validation failures
**Common Scenarios**:
- Event not found or already deleted
- User lacks permission to cancel the event
- User is not the event organizer
- Event is already cancelled

**Resolution**: Verify event exists, user has permissions, and user is authorized to cancel

### System Errors (SYSTEM_ERROR)
**Cause**: Google Calendar API failures or network issues
**Common Scenarios**:
- API rate limiting
- Network connectivity problems
- Google service outages
- Authentication token expiration

**Error Message**: "Event cancellation failed: Unable to cancel calendar event. Required: Valid Event ID and organizer permissions. Resolution: Verify event exists, user has organizer permissions, and check Google Calendar API connectivity."

**Resolution**: Retry request after delay or re-authenticate if needed

### Authorization Errors
**Cause**: Insufficient permissions or expired authentication
**Common Scenarios**:
- User not authorized to cancel the event
- OAuth token expired or invalid
- Calendar access permissions revoked

**Resolution**: Re-authenticate or verify calendar permissions and organizer status

## Business Rules

1. **Organizer Authority**: Only event organizers can cancel events (unless admin permissions)
2. **Automatic Notifications**: Google Calendar automatically sends cancellation notifications to all attendees
3. **Calendar Removal**: Event is removed from all attendees' calendars immediately
4. **Idempotent Operation**: Cancelling an already cancelled event has no negative effect
5. **Resource Liberation**: Cancellation frees up meeting rooms and resources
6. **Audit Trail**: Cancellation is logged in Google Calendar audit logs
7. **No Recovery**: Cancelled events cannot be directly restored (must be recreated)

## Limitations

1. **Organizer Only**: Only event organizers can cancel events (with some admin exceptions)
2. **No Partial Cancellation**: Cannot cancel for specific attendees only
3. **No Undo Function**: No direct way to restore cancelled events
4. **Permission Dependent**: Requires appropriate calendar permissions
5. **API Rate Limits**: Subject to Google Calendar API quotas
6. **No Bulk Operations**: Cannot cancel multiple events simultaneously

## Technical Implementation

### Helper Class
- **Class**: MeetingAreaImpl
- **Package**: app.kristasoft.extensions.essentials.collaboration.google_calendar.impl
- **Method**: cancelEvent(String eventId)
- **Service**: Google Calendar API events.delete()

### Implementation Details
1. **Retrieve Event**: Get event details using events.get() before deletion
2. **Store Event Details**: Capture event information for return value
3. **Delete Event**: Use events.delete() to remove event from calendar
4. **Return Details**: Return the event details as they existed before cancellation

### API Integration
- **API Endpoint**: Google Calendar API v3 events.delete
- **Authentication**: OAuth 2.0 with calendar scope
- **Request**: DELETE /calendars/primary/events/{eventId}
- **Response**: Success confirmation (200 OK)

### Cancellation Process
The system follows this process:
1. Validates Event ID format and existence
2. Checks user permissions and organizer status
3. Retrieves event details for return value
4. Executes deletion through Google Calendar API
5. Returns original event details to confirm cancellation

## Troubleshooting

### Event Not Found
**Cause**: Invalid Event ID or already deleted event
**Solution**: Verify Event ID is correct and event still exists

### Permission Denied
**Cause**: User is not the event organizer or lacks delete permissions
**Solution**: Ensure user is the organizer or has admin rights

### Already Cancelled
**Cause**: Event was previously cancelled (not an error)
**Solution**: Operation completes successfully due to idempotent nature

### Authentication Errors
**Cause**: Expired or invalid OAuth token
**Solution**: Re-authenticate and refresh access token

### API Rate Limiting
**Cause**: Too many requests in short time period
**Solution**: Implement exponential backoff and respect rate limits
