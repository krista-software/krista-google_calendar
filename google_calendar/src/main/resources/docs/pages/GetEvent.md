# Get Event

## Overview

Retrieves detailed information for a specific calendar event using its unique Event ID.

## Request Details

- **Area**: Meetings
- **Type**: QUERY_SYSTEM
- **Retry Support**:  Yes (Read-only operation is safe to retry)

## Input Parameters

| Parameter Name | Type | Required | Description | Example |
|----------------|------|----------|-------------|---------|
| Event ID | Text | Yes | Unique identifier of the calendar event | "abc123def456ghi789" |

### Parameter Details

**Event ID**:
- Unique identifier generated by Google Calendar when event is created
- Case-sensitive alphanumeric string
- Obtained from other catalog requests like Schedule Meeting or Get Next Upcoming Meetings
- Format varies but typically 26+ characters long

## Output Parameters

| Parameter Name | Type | Description |
|----------------|------|-------------|
| Event Details | Entity(Event Details) | Complete event information |

### Event Details Entity Structure

- **Event Id**: Unique event identifier
- **Title**: Event title/summary
- **Location**: Event location or venue
- **Date From**: Event start date and time (Unix timestamp)
- **Date To**: Event end date and time (Unix timestamp)
- **Details**: Event description/agenda
- **Contacts**: List of attendee email addresses

## Validation Rules

| Validation | Error Message | Resolution |
|------------|---------------|------------|
| Event ID is required | "Event ID cannot be empty" | Provide a valid Event ID |
| Event ID format validation | "Invalid Event ID format" | Ensure Event ID is properly formatted |
| Event must exist | "Event not found" | Verify Event ID exists and is accessible |

## Error Handling

### Input Errors (INPUT_ERROR)
**Cause**: Invalid or missing Event ID parameter
**Common Scenarios**:
- Empty or null Event ID
- Malformed Event ID string
- Event ID with invalid characters

**Resolution**: Provide a valid Event ID obtained from other calendar operations

### Logic Errors (LOGIC_ERROR)
**Cause**: Event access or permission issues
**Common Scenarios**:
- Event not found in accessible calendars
- Event deleted or cancelled
- Insufficient permissions to view event

**Resolution**: Verify event exists and user has appropriate calendar access

### System Errors (SYSTEM_ERROR)
**Cause**: Google Calendar API failures or network issues
**Common Scenarios**:
- API rate limiting
- Network connectivity problems
- Google service outages
- Authentication token expiration

**Resolution**: Retry request after delay or re-authenticate if needed

### Authorization Errors
**Cause**: Insufficient permissions or expired authentication
**Error Messages**:
- "Event retrieval failed: Unable to fetch calendar event details. Required: Valid Event ID and calendar read permissions. Resolution: Verify event ID exists, check calendar access permissions, and ensure Google Calendar API connectivity."
- "Calendar access denied"

**Resolution**: Re-authenticate or verify calendar permissions

## Business Rules

1. **Event Visibility**: Only events visible to the authenticated user can be retrieved
2. **Calendar Access**: User must have read access to the calendar containing the event
3. **Event Status**: Returns events regardless of status (confirmed, tentative, cancelled)
4. **Attendee Information**: Full attendee list is returned if user has appropriate permissions
5. **Time Zone**: Date/time values are returned in the event's original timezone
6. **Deleted Events**: Deleted events cannot be retrieved and will return "not found" error
7. **Private Events**: Private event details may be limited based on user permissions

## Limitations

1. **Single Event Only**: Retrieves one event per request (no batch operations)
2. **Read-Only Access**: Cannot modify event through this request
3. **Permission Dependent**: Event details depend on user's calendar permissions
4. **No Historical Data**: Cannot retrieve events that have been permanently deleted
5. **API Rate Limits**: Subject to Google Calendar API quotas
6. **Timezone Complexity**: Date/time interpretation may vary based on user settings

## Best Practices

### 1. **Event ID Validation**
Always validate Event ID format before making requests to avoid unnecessary API calls

### 2. **Error Handling**
Implement proper error handling for "event not found" scenarios

### 3. **Caching Strategy**
Consider caching event details for frequently accessed events to reduce API calls

### 4. **Permission Awareness**
Be aware that event details may vary based on user's calendar permissions

### 5. **Retry Logic**
Implement retry logic for transient failures while respecting API rate limits

## Technical Implementation

### Helper Class
- **Class**: MeetingAreaImpl
- **Package**: app.kristasoft.extensions.essentials.collaboration.google_calendar.impl
- **Method**: getEvent(String eventId)
- **Service**: Google Calendar API events.get()

### API Integration
- **API Endpoint**: Google Calendar API v3 events.get
- **Authentication**: OAuth 2.0 with calendar scope
- **Request**: GET /calendars/primary/events/{eventId}
- **Response**: Complete Event object with all details

### Event Processing
The system uses `EventDetails.getEventDetailsByEvent()` to convert Google Calendar Event objects:
- Extracts event metadata (ID, title, location)
- Processes date/time information
- Converts attendee list to email array
- Handles null values and missing fields

## Troubleshooting

### Event Not Found
**Cause**: Invalid Event ID or insufficient permissions
**Solution**: Verify Event ID and check calendar access permissions

### Permission Denied
**Cause**: User lacks read access to the calendar
**Solution**: Ensure user has appropriate calendar permissions

### Authentication Errors
**Cause**: Expired or invalid OAuth token
**Solution**: Re-authenticate and refresh access token

### API Rate Limiting
**Cause**: Too many requests in short time period
**Solution**: Implement exponential backoff and respect rate limits
